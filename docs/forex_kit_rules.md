# FOREX KIT :: Правила торговой системы
Источник: 28 видео курса FOREX KIT + скриншоты.
Дата: 2026-10-02.
---
## 1. Инструментарий
- **Платформа:** SB Pro (кластерный анализ).
- **Индикаторы:** кластеры, дельта, тотал-дельта, профиль BitAsk, вертикальный объём.
- **Классические индикаторы не использовать.**
- **Таймфрейм:** M5 (основной).
- **Данные для бэктеста:** ClusterDelta CSV (my.clusterdelta.com/files).
---
## 2. Терминология
| Термин | Определение |
|---|---|
| Стоп-лосы покупателей | Рыночные покупки по Ask. Нули справа. |
| Стоп-лосы продавцов | Рыночные продажи по Ask. Нули слева. |
| Распродажа | Ликвидная зона. Закрыта цифрами сверху и снизу. |
| Плита | Консолидация из Sell/Buy одинаковых контрактов. |
| Скрытый уровень | Уровень, спрятанный крупным игроком. Толпа не видит. |
| Боковик | Не менее 4 касаний. Цена в рамках. |
| V-уровень | Резкий импульс за 2-9 свечей. Не перебит. |
| Зеркальный уровень | Уровень пробит, ретестнут, снова отработал. |
| Тень | Зона крупного лимитного покупателя. |
---
## 3. Распродажа vs стоп-лосы
- **Стоп-лосы**: нули, ничем не закрыты сверху/снизу.
- **Распродажа**: всегда закрыта цифрами сверху и снизу.
Торговля: свеча с распродажей = крупный игрок + толпа. Строится диапазон high-low. Вход от границ.
---
## 4. Крупный игрок
### 4.1. Вход продавца
- На растущей свече.
- Через Ask.
- Парные или одинаковые цифры (12-12, 18-18, 22-22, 26-26, 41-41).
- Признак: разворот вниз.
### 4.2. Вход покупателя
- На падающей свече.
- Через Bid.
- Парные или одинаковые цифры (7-7, 21-21, 42-42, 13-13).
- Признак: разворот вверх.
### 4.3. Завершение позиции
- Крупный игрок закрывает теми же контрактами, которыми набирал.
- Начал 6-6 -> закончит 6-6.
- Начал 8-8 -> закончит 8-8.
### 4.4. Скрытый уровень (формула)
1. Число контрактов в дельте умножить на 100 000 = объём в долларах.
2. Разделить на 2 (заявка на 2 стороны).
3. Убрать три нуля = значение дельты, ровное уровню.
Пример: (300 * 100 000) / 2 = 150 000 -> убираем 3 нуля -> 150.
---
## 5. Иллюзия рынка
Формула:
    Толпа - заявка крупного игрока = ликвидность толпы через уровень
На свечном графике "цена есть". На Line - "цены нет". Толпа видит ложный уровень, крупный игрок - реальный.
---
## 6. Правила торговли
### 6.1. Боковик
- Не менее 4 касаний. Цена в рамках.
- Натянуть профиль BitAsk от начала до пробоя.
- Кого больше:
  - Покупателей -> цена пойдёт вниз.
  - Продавцов -> цена пойдёт вверх.
- Потенциал движения = ширина боковика * 2.
- Закрывать 50% на первой цели, остаток тянуть.
### 6.2. Снятие стопов
- Определить нули в кластерах.
- Выделить область (не линию).
- Вход чуть раньше касания.
- Стоп: 10-20 пунктов.
- Профит: 80-250 пунктов.
### 6.3. V-уровни
- Резкий импульс (2-9 свечей).
- Не перебит.
- Натянуть Fibo: только 0%, 50%, 100%.
- Пробитие + ретест -> вход.
### 6.4. Распродажа
- Свеча с аномальным объёмом.
- Выделить полностью high-low.
- Вход от границ зоны.
- Профит: 75-90 пунктов.
### 6.5. Зеркальный уровень
- Уровень держали -> пробили -> ретест.
- На ретесте собираются стопы.
- Вход от ликвидности, стоп за уровень.
### 6.6. Плита
- Одинаковые цифры сверху и снизу.
- Уровень через плиту.
- На ретесте вход в продажи.
### 6.7. Тень
- После сильного роста тень указывает на лимитного покупателя.
- Крупный игрок часто заходит в тенях.
### 6.8. Уровень крупного игрока
- Держит только крупный игрок.
- Нет крупного -> уровень пробьётся, вход в пробой.
- Есть крупный -> цена не пустит ниже/выше его позиции.
### 6.9. Новости
- Перед новостью держат уровень (по хаям).
- На новости цена идёт в направлении крупного игрока.
- Вход от ликвидности толпы после новости.
---
## 7. Многофакторный анализ
Минимум 2-3 фактора перед входом:
1. Боковик / V-уровень / распродажа.
2. Снятие стопов / зеркальный уровень / плита.
3. Крупный игрок (парные цифры).
4. Дельта / тотал-дельта.
5. Тень / профиль BitAsk.
Чем больше факторов, тем сильнее сигнал.
---
## 8. Чего не делать
- Не торговать на новостях - только ждать реакцию.
- Не верить фундаменталу.
- Не путать свечу роста с покупкой (толпа может ошибаться).
- Не путать распродажу с отсутствием объёма.
- Не путать стопы со снятием ликвидности.
- Не рисовать треугольники (это не боковики).
- Не использовать классические индикаторы.
- Не путать плиту с консолидацией.
---
## 9. Торговый процесс
1. Открыть график M5.
2. Найти формацию (боковик / V-уровень / распродажа / плита / зеркало).
3. Натянуть профиль BitAsk.
4. Определить перевес покупателей/продавцов.
5. Найти крупного игрока (парные цифры).
6. Проверить дельту.
7. Комбинировать 2-3+ фактора.
8. Вход:
   - С лимита - на границе зоны.
   - С рынка - после ретеста.
9. Стоп: за уровнем, короткий.
10. Профит:
    - 50% на первой цели.
    - Остаток до потенциала (ширина * 2).
---
## 10. Психология
- Толпой правят страх и невежество.
- Крупный игрок никогда не отдаст свою позицию.
- Цена не пойдёт против позиции крупного игрока.
- Если 95% торгуют против крупного, они теряют.
- Тренироваться на симуляторе SB Pro, не на истории.
---
## 11. Открытые вопросы для формализации
Требуют уточнения у автора курса или из скриншотов:
1. Точный порог "парных цифр" - какие считаются сигналом (2-2, 6-6, 8-8, 12-12?).
2. Настройки профиля BitAsk.
3. Настройки дельты (период, фильтры).
4. Формула по хаям (упомянута, без деталей).
5. Как точно определяется "крупный игрок" (только цифры или ещё объём).
