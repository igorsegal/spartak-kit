# 02. Структура
**Статус:** утверждено
**Источник:** Ч.1, Ч.2, Ч.4, Ч.6, Ч.8
**Обновлено:** 2026-10-03
Структура системы — это пять терминов.
Эти термины образуют две формулы.
Формула 1: IT + ZO = ORT.
Формула 2: ORT + ZO = IT.
---
## Термин: Закрепление
**Определение.**
Закрепление — это сигнал подтверждения.
Цена выходит из зоны.
Цена оставляет минимум одну откатную свечу.
Цена оставляет одну свечу в сторону пробития.
Эта свеча закрывается за границей зоны.
**Как найти.**
1. Найди зону аккумуляции.
2. Найди выход цены из зоны.
3. Найди откатную свечу. Это свеча против движения.
4. Найди свечу в сторону пробития. Это свеча по движению.
5. Проверь закрытие. Закрытие должно быть за границей зоны.
**Что делать.**
1. Входи в сделку только после закрепления.
2. Не входи до закрепления.
3. Ставь стоп за зону закрепления.
**Ошибки.**
- Путают закрепление с одним баром. Закрепление — это минимум два бара.
- Путают закрепление с пробоем. Пробой — это один бар.
- Входят на пробое. Это ложный вход.
**Источник.**
Ч.6 — «Закрепление — это минимум одна откатная свеча и одна свеча в сторону пробития».
Ч.8 — «Закрепление — это факт, что маркетмейкер не находит больше игроков».
**Статус.** утверждено

## Термин: IT (Источник Тренда)
**Определение.**
IT — это уровень.
Это первый уровень после разворота.
Это граница между старой и новой тенденцией.
Это зона, где маркетмейкер открыл позицию.
**Как найти.**
1. Найди разворотный момент.
2. Найди первый уровень после разворота.
3. Проверь. Уровень не пробит после разворота.
4. Проверь. Уровень ведёт к новой тенденции.
**Что делать.**
1. Входи в IT по сигналу ZO.
2. Цель — ORT.
3. Стоп — за IT.
**Ошибки.**
- Путают IT с локальным уровнем. Локальный уровень — внутри тенденции. IT — начало тенденции.
- Путают IT с ZO. IT — это уровень. ZO — это сигнал.
- Путают IT с PU. PU — внутри тенденции.
**Источник.**
Ч.4 — «IT — это первый уровень поддержки или сопротивления после разворота».
Ч.8 — «IT — это зона, где маркетмейкер формирует позицию».
**Статус.** утверждено

## Термин: ZO (Запертый Объём)
**Определение.**
ZO — это сигнал входа.
Это зона, где цена завершает движение.
Это зона, где маркетмейкер запирает позиции.
Это зона, где продавцы или покупатели остаются в ловушке.
**Как найти.**
1. Найди зону аккумуляции.
2. Найди выход цены из зоны.
3. Проверь. Цена не возвращается в зону.
4. Проверь. Цена закреплена за границей.
**Что делать.**
1. Входи в сделку после ZO.
2. Цель — ORT или IT.
3. Стоп — за ZO.
**Ошибки.**
- Путают ZO с аккумуляцией. Аккумуляция — до выхода. ZO — после выхода.
- Путают ZO с IT. IT — это уровень. ZO — это сигнал.
**Источник.**
Ч.2 — «ZO — это единственный торговый сигнал на графике».
Ч.6 — «ZO — это зона, где запирается объём».
**Статус.** утверждено

## Термин: ORT (Область Разворота Тенденции)
**Определение.**
ORT — это зона.
Это зона за IT.
Это зона, где тенденция меняет направление.
Это зона, где силы слабой стороны закончились.
**Как найти.**
1. Найди IT.
2. Найди зону за IT.
3. Проверь. Зона за максимумом для верхней ORT.
4. Проверь. Зона за минимумом для нижней ORT.
**Что делать.**
1. Входи в ORT по сигналу ZO.
2. Цель — IT предыдущего импульса.
3. Стоп — за ORT.
**Ошибки.**
- Путают ORT с IT. IT — уровень. ORT — зона.
- Путают ORT с PU. PU — внутри тенденции.
**Источник.**
Ч.2 — «ORT — это зона за максимумом или минимумом IT».
Ч.4 — «ORT — это зона, где тактическое преимущество теряется».
**Статус.** утверждено

## Термин: RM (Разворотный Момент)
**Определение.**
RM — это формация на графике.
Это сигнал смены направления.
Это зона, где маркетмейкер закрывает позицию.
Это момент, когда цена меняет направление.
**Как найти.**
1. Найди зону аккумуляции.
2. Найди выход цены из зоны.
3. Найди закрепление.
4. Проверь форму. Форма RM — одна из четырёх.
**Четыре формы RM.**
1. RM 1.1 — резкая свеча, откат, закрепление.
2. RM 1.2 — двойная вершина, закрепление.
3. RM 2.1 — выход из фигуры, закрепление.
4. RM 2.2 — заныривание в зону, закрепление.
**Что делать.**
1. Входи в RM после закрепления.
2. Цель — ORT или IT.
3. Стоп — за RM.
**Ошибки.**
- Путают RM с коррекцией. Коррекция — внутри тенденции. RM — смена тенденции.
- Путают RM с ZO. ZO — сигнал. RM — формация.
**Источник.**
Ч.6 — «RM — это четыре формы разворота».
Ч.8 — «RM — это сигнал смены направления».
**Статус.** утверждено
