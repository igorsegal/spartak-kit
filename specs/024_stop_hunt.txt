ТЗ: StopHuntDetector (версия 2, финал)

НАЗНАЧЕНИЕ
Детектор снятия стопов. Цена импульсно прокалывает уровень, затем быстро возвращается и уходит в обратную сторону.

ИСТОЧНИК ПРАВИЛ
Пункт 7.2: требует уровня. Без уровня - пустота, не снятие стопов.
Пункт 7.2: стопы покупателей - рыночные покупки по Bid, нули справа, под ценой.
Пункт 7.2: стопы продавцов - рыночные продажи по Ask, нули слева, над ценой.
Пункт 7.2: направление после снятия стопов продавцов - вниз.
Подтверждено: L02, L08.2, L12, L14, L17, R_L02.

ОПРЕДЕЛЕНИЯ
Уровень - high или low валидного бара. Доджи (high == low) НЕ даёт уровней.
Касание - бар с low <= level + tol И high >= level - tol.
Прокол вверх - бар j, где close[j] > level + tol И close[j-1] <= level + tol.
Прокол вниз - бар j, где close[j] < level - tol И close[j-1] >= level - tol.
Возврат - бар m > j, где close[m] вернулся в зону уровня [level - tol, level + tol].

ЛОГИКА НАПРАВЛЕНИЯ
Прокол вверх = снятие стопов продавцов. Их стопы стояли над ценой. После снятия - разворот вниз. direction = Sell.
Прокол вниз = снятие стопов покупателей. Их стопы стояли под ценой. После снятия - разворот вверх. direction = Buy.

ОТЛИЧИЕ ОТ FalseBreakoutDetector
FalseBreakout: close за уровнем + закрепление (2+ бара) + возврат.
StopHunt: импульсный прокол (1-3 бара) + быстрый возврат. Закрепления нет.
Формации взаимоисключающие, разрешение конфликта - CompositeSignal.

ПОРЯДОК ШАГОВ
1. Отфильтровать бары: NaN/Inf в ценах и объёмах, high < low, отрицательные объёмы, volume > 0 при ask+bid == 0.
2. Проверить число валидных баров >= min_bars_for_hunt. Иначе ok false.
3. Если валидных баров > window_size - обрезать до последних window_size.
4. Повторно проверить число баров >= min_bars_for_hunt. Иначе ok false.
5. Найти min_low и max_high. range > 0. Иначе ok false.
6. tol = range * zone_tolerance_range. Проверить tol > 0 и tol < range.
7. Собрать кандидаты-уровни: high и low валидных не-доджи баров.
8. Уникализировать уровни: если два отличаются на <= tol - оставить первый.
9. Отсортировать уровни по индексу первого касания (по возрастанию).
10. Для каждого уровня:
    a. Найти все касания.
    b. Если касаний < min_touches - уровень пропускается.
    c. Найти первый прокол в окне [last_touch + 1, last_touch + max_pierce_bars].
    d. Если прокола нет - уровень пропускается.
    e. Найти первый возврат в окне [pierce_idx + 1, pierce_idx + max_pierce_bars].
    f. Если возврата нет - уровень пропускается.
    g. Сформировать сигнал: direction = Sell при проколе вверх, Buy при проколе вниз.
    h. touches_before = число касаний до прокола.
11. Сканировать все валидные сигналы. Выбирать с максимальным touches_before.
    При равенстве - раньше найденный (по порядку уровней из шага 9).
12. bars_outside = return_idx - pierce_idx.

ДОПУСК
tol = range * zone_tolerance_range.

ПАРАМЕТРЫ (требуют калибровки)
zone_tolerance_range = 0.01
min_bars_for_hunt = 20
min_touches = 2
max_pierce_bars = 3
window_size = 200

ВЫХОД StopHuntSignal
ok bool
direction OrderSide - Sell при проколе вверх, Buy при проколе вниз
level double
level_ts int64 - время первого касания уровня
touch_ts int64 - время последнего касания перед проколом
pierce_ts int64 - время прокола
return_ts int64 - время возврата
pierce_extreme double - max high (прокол вверх) или min low (прокол вниз) в окне [last_touch, pierce_idx]
close_at_return double
touches_before int
bars_outside int - return_idx - pierce_idx

При ok == false все числовые поля = 0, direction = Buy (значение по умолчанию).

ВАЛИДАЦИЯ ПАРАМЕТРОВ
zone_tolerance_range в (0, 1).
min_bars_for_hunt >= 10.
min_touches >= 1.
max_pierce_bars в [1, 10].
window_size >= min_bars_for_hunt и <= 100000.
Иначе ok false.

КРАЕВЫЕ СЛУЧАИ
Пустой вход - ok false.
Валидных баров меньше min_bars_for_hunt - ok false.
После обрезки меньше min_bars_for_hunt - ok false.
range <= 0 - ok false.
tol <= 0 или tol >= range - ok false.
Нет ни одного уровня с проколом и возвратом - ok false.
Все бары - доджи - ok false.
Прокол на последнем баре - возврата нет, уровень пропускается.
Параметры не прошли валидацию - ok false.

ЧЕГО ДЕТЕКТОР НЕ ДЕЛАЕТ
Не ищет боковик.
Не проверяет тренд.
Не блокирует CompositeSignal.
Не ищет зеркальный уровень (задача MirrorLevelDetector).
Не разрешает конфликт с FalseBreakoutDetector.

СЛОЖНОСТЬ
O(n * k), k - число уровней-кандидатов.
